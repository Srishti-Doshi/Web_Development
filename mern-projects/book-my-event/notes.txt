dependencies: Add functionality/features to your backend
    bcryptjs => used to hash (encrypt) passwords
    cors => cross origin resource sharing(frontend backend communication)
    dotenv => loads environment variables from .env file
    express.js => backend Logic , helps us create server(program that handles requests and sends responses) easily
    jsonwebtoken => tokenization, login logout, JWT is used for authentication (login verification)
    Login → server gives token → user sends token → access granted

    mongoose => helps us connect and interact with MongoDB
    nodemailer => used to send emails (OTP, notifications, etc.) from backend
